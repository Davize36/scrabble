# Scrabble Game (Vue + WebSocket)

Quick demo of a Scrabble-like game with a lobby and simple WebSocket rooms.

Run locally:

```bash
npm install
# start the WebSocket server
npm run server
# in another terminal start the dev frontend
npm run dev
```

Open multiple browser windows, enter the same room code on the lobby page to join the same game.
